### Sobre mí

Desarrollador full stack con foco en **operaciones reales**: inventarios, alertas, sincronización de datos y automatización. Combino reglas de negocio, APIs y UI, e integro **IA** y **n8n** cuando el proceso lo pide.

- **Ops / industria:** inventarios, cortes, documentos y trazabilidad
- **Automatización:** n8n + APIs + bases de datos
- **IA aplicada:** extracción, clasificación y agentes sobre datos propios
- **Full stack:** FastAPI, React/TypeScript, PostgreSQL, Docker en VPS
